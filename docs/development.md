# Разработка

Нужны Go 1.25+, Node.js 22+ и npm. AWS CLI и rclone используются для дополнительных интеграционных проверок; Docker — для контейнерной сборки.

```sh
npm ci
npm test
npm run build:css
go test -race ./...
go vet ./...
go build -trimpath -o bin/maxstore ./cmd/maxstore
```

`web/style.css` коммитится вместе с исходниками: Go-сборка не требует Node или CDN. HTML/JS/CSS встроены через go:embed. После изменения frontend пересоберите бинарник и перезапустите процесс; редактирование файлов на диске не меняет уже запущенный интерфейс.

## Структура

- `cmd/maxstore`: конфигурация, учётные данные, серверы и штатное завершение.
- `internal/store`: bbolt, части, шифрование, multipart, потоковый reader, очередь очистки.
- `internal/provider`: локальный диск, Telegram и MAX.
- `internal/server`: консоль, сессии, HTTP API, S3 и SigV4.
- `web`: Tailwind и интерфейс; независимый планировщик `upload-queue.js` тестируется Node test runner.
- `scripts/s3-smoke.py`: изолированный прогон AWS CLI и rclone.

## Проверки

Go-тесты проверяют шифрование, отказ при повреждении, multipart, конкурентную запись и чтение, возобновление, ошибки провайдеров и подписи. Тесты официального AWS SDK используют локальный HTTP endpoint. Удалённые адаптеры тестируются через TLS mock и не требуют пользовательских токенов. JavaScript-тесты проверяют независимость файлов, добавление новой партии, общий лимит, ошибки, паузу/продолжение и пустые файлы.

Все тесты создают временные каталоги. Не запускайте smoke-тесты на пользовательских бакетах. `go test -race ./...` и `go vet ./...` обязательны перед выпуском.

## CI и выпуск

GitHub Actions устанавливает зависимости, собирает CSS, проверяет формат Go, запускает Node и Go-тесты с race detector, vet и сборку. Отдельная задача проверяет Docker build.

Для релиза используйте тег `vX.Y.Z` после успешного CI. Workflow собирает архивы для Linux/macOS amd64/arm64 и Windows amd64, публикует SHA256SUMS и GitHub Release. Перед тегом обновите CHANGELOG и package.json. Сборочные артефакты не содержат DATA_DIR или .env.
