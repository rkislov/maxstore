# Конфигурация

Сервер получает настройки из окружения. [`.env.example`](../.env.example) содержит безопасные примеры. Для запуска без Docker экспортируйте их оболочкой. Пути относительны к рабочему каталогу процесса.

## Адреса и данные

- `HTTP_ADDR`: `127.0.0.1:8080`, консоль и HTTP API.
- `S3_ADDR`: `127.0.0.1:9000`, S3 API.
- `S3_PUBLIC_ENDPOINT`: `http://127.0.0.1:9000`, адрес в консоли и multipart-ответах; задайте внешний адрес при использовании reverse proxy.
- `DATA_DIR`: `data`, закрытый каталог с ключом, метаданными, учётными данными и локальными частями.
- `DEFAULT_PROVIDER`: `local`; возможны `local`, `telegram`, `max`. Провайдер должен быть настроен. Используется при создании бакетов через S3 без заголовка `X-Maxstore-Provider`.
- `MAX_OBJECT_SIZE`: `0`, без настроенного лимита; положительное значение задаёт байты.
- `UPLOAD_CONCURRENCY`, `DOWNLOAD_CONCURRENCY`: `4`, допустимо 1–16. Общие лимиты операций провайдера для всего процесса.

## Авторизация

- `ADMIN_USERNAME`, `ADMIN_PASSWORD`: используются для создания администратора **только при первой инициализации аккаунта**. Пароль 12–72 байта. После создания bcrypt-хеш хранится в БД; изменение переменной не меняет существующий пароль.
- `COOKIE_SECURE`: `false`, установите `true` при работе за HTTPS proxy.
- `CONSOLE_TOKEN`: дополнительный bearer-токен HTTP API, минимум 16 символов. Без переменной генерируется в `credentials.json`.
- `S3_ACCESS_KEY`, `S3_SECRET_KEY`: независимые ключи SigV4; секрет минимум 16 символов. Без переменных генерируются в `credentials.json`.

Файл `credentials.json` содержит начальный пароль в открытом виде для первого входа. Храните каталог закрытым (`0700`, файлы ключей `0600`). При явных ADMIN_* фактический начальный пароль берётся из окружения; сгенерированный пароль в файле не заменяет его. Управления несколькими пользователями и сброса пароля через интерфейс пока нет.

## Провайдеры

- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`: вместе подключают Telegram.
- `MAX_BOT_TOKEN`, `MAX_CHAT_ID`: вместе подключают MAX.
- `SSL_CERT_FILE`: стандартная настройка Go TLS для дополнительного доверенного корневого сертификата, если это требуется окружением.

Токены не передаются браузеру. Смена бота/чата не переносит существующие части: старые объекты могут потерять доступ к данным. Сначала перенесите объекты через S3 в новый бакет и проверьте скачивание.
