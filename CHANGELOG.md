# История изменений

## 0.1.0

Первый публичный выпуск MaxStore.

- Хранилище на Go с AES-256-GCM, bbolt и провайдерами Telegram, MAX и локальным диском.
- S3 SigV4, presigned URLs, основные операции бакетов/объектов, multipart, копирование, теги, массовое удаление, метаданные и условная запись.
- Tailwind CSS, светлая/тёмная тема, вход по логину и паролю.
- Независимая очередь файлов и общий пул потоков, пауза и продолжение, сохранение принятых частей.
- Потоковое скачивание, параллельная подкачка, HTTP Range и проверка целостности.
- Docker Compose, GitHub Actions, тесты очереди и официального AWS SDK, инструкции по запуску и восстановлению.

Автор: Кислов Роман Сергеевич. Apache 2.0.
