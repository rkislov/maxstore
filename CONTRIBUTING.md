# Участие в разработке

Автор проекта — Кислов Роман Сергеевич. Вклады принимаются по Apache 2.0.

Перед изменениями прочитайте [архитектуру](docs/architecture.md) и [совместимость S3](docs/s3.md). Для исправления ошибки приложите воспроизводимый пример с синтетическими данными. Не прикладывайте доступ к личным ботам.

Проверки: `npm ci`, `npm test`, `npm run build:css`, `go test -race ./...`, `go vet ./...`, `go build ./cmd/maxstore`. Форматируйте Go через gofmt. Новые протокольные операции проверяйте реальным AWS SDK и сценариями ошибок, особенно атомарностью записи и сохранением старого объекта после неудачи.

Pull request должен объяснять проблему, поведение после исправления, проверки и ограничения. Если изменились API, конфигурация или гарантия хранения — обновите документацию и CHANGELOG.
